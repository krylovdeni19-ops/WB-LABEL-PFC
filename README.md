# Генератор мест хранения (МХ) и этикеток

Автономное веб-приложение для формирования адресов мест хранения и печати QR-этикеток.

## Возможности

- Создание одного или нескольких блоков стеллажей.
- Настройка диапазона стеллажей, количества полок и ячеек.
- Автоматическое формирование адресов вида `01.01.01`.
- Генерация QR-кодов для адресов МХ.
- Предварительный просмотр списка.
- Экспорт списка МХ в CSV.
- Печать этикеток или сохранение в PDF через диалог печати браузера.

## Конфиденциальность и зависимости

Приложение работает полностью в браузере. Оно не подключается к Supabase, REST API или другим внешним сервисам и не отправляет введённые данные на сервер.

Внешние JavaScript-библиотеки и CDN не используются.

## Запуск локально

1. Скачайте репозиторий или файл `index.html`.
2. Откройте `index.html` в современном браузере.
3. Настройте блоки и нажмите **«Создать МХ и этикетки»**.

Для печати выберите **«Печать этикеток / Сохранить PDF»**. В настройках печати укажите масштаб 100% и отключите поля и колонтитулы, если браузер предлагает такие параметры.

Формат этикетки в CSS для печати: 100 × 20 мм.

## Публикация через GitHub Pages

1. Создайте новый GitHub-репозиторий.
2. Загрузите в корень репозитория `index.html` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем сохраните.
6. После публикации GitHub Pages покажет адрес сайта.

## Важно

Перед массовой печатью проверьте несколько QR-кодов сканером и сделайте тестовую печать: фактический размер зависит от настроек принтера и браузера.
